# Notchwheel

A macOS menu bar app that compresses and converts images the moment you drag them. Hold ⌥ while
dragging any image file and a radial wheel appears under the cursor; drop onto a segment and the
processed file lands next to the original. A notch-style pill shows progress and the result.

Status: planning. See [PRD.md](PRD.md) for scope, requirements and the build plan.

Requirements: macOS 14+, Apple silicon.
